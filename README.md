# Portfólio · Relações, Princípios e Valores (2026)

Portfólio de **Lucas Aires Leite**, estudante de Engenharia de Software, com os registros dos encontros da disciplina *Relações, Princípios e Valores*.

🔗 **Ver online:** https://lucasairesleite01-rgb.github.io/portfolio-rpv/

## Sobre o projeto

Página única em HTML, CSS e JavaScript, sem dependências nem etapa de build. Fotos e vídeos estão embutidos no próprio arquivo. A única coisa externa é a fonte *Inter Tight*, do Google Fonts.

## Estrutura

```
.
├── index.html   # o portfólio inteiro (estilos, conteúdo e scripts)
├── README.md
└── .gitignore
```

## Como abrir

Dê dois cliques em `index.html` para abrir no navegador.

## Como editar

Cada seção tem um *slide* (`<li class="slot">`) e uma *página aberta* (`<section class="sheet">`). Para criar uma seção nova, copie os dois, troque o `id` nos dois lugares e edite os textos. As instruções completas estão no comentário no topo do `index.html`.
